# Code of Conduct

Finlume adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to all project
spaces: the repository, issues, pull requests, discussions and any other
channel run by the project, and to anyone representing the project
elsewhere.

## In short

- Be welcoming, patient and respectful. Disagree about ideas, not people.
- Give and accept constructive feedback gracefully.
- No harassment, discrimination, personal attacks, trolling or sexualised
  language or imagery.
- Never publish anyone's private information. That includes their financial
  information, which this project treats as especially sensitive.

## Reporting

Report unacceptable behaviour to the project maintainer,
[@Kiritiaajd](https://github.com/Kiritiaajd). A dedicated, private
conduct-reporting address will be published in this section. Until then, ask
in a minimal public issue for a private contact, without describing the
incident. All reports are reviewed promptly and handled confidentially.

## Enforcement

Maintainers enforce this code following the Contributor Covenant's
enforcement guidelines (correction, warning, temporary ban, permanent ban),
proportionate to the impact of the behaviour.
